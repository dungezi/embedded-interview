## 在线体验

[点击进入在线刷题](https://dungezi.github.io/embedded-interview/)

## 项目介绍

这是一个基于 React + TypeScript + Vite 开发的嵌入式面试刷题 Web App。

支持方向筛选、题型筛选、错题本、收藏、学习统计和本地学习记录。

用户数据保存在浏览器本地，不依赖后端服务器或数据库。



用于整理和练习嵌入式相关面试题。



目前计划包含：



\- C语言

\- STM32

\- FreeRTOS

\- Linux

\- FPGA

\- 数据结构与算法
